# Changelog

- 1.21.0 (2026-10-23)
  - Account positions now include excluded holdings, returned with `excluded: true`; `excluded` is writable, and a position sent without it keeps its current state. See [excluded positions](#excluded-positions).
  - Updating a holding the account already has now applies `purchase_date` and `unrealized_gains` when they are sent, and keeps them when they are not.
  - Add read-only `id` (stable while the holding keeps its identifier), `created_at` and `updated_at` (moves only when a value changes) to account and model portfolio positions.
- 1.20.0 (2026-10-23)
  - Add `is_benchmark` and `visibility` (`public` or `private`) to `/models/`, writable on create and update, plus read-only `created_at`, `updated_at`, `display_name`, `sync_status`, `sync_status_changed`, `integration_link_updated_at`, `is_security_origin`, `security_origin` (ticker) and `source_account` (account id).
  - Advisors who are not managers follow the StratiFi app's rules: they update and delete only their own models, see private models only when they own them or share a team, and share models, or manage benchmarks and strategies, only when the firm allows it.
  - `company` is required on create; `advisor` can be sent by a manager.
- 1.19.0 (2026-10-23)
  - Add `investment_objective`, `investment_objective_custom`, `advisory_fee` and `exceptions_enabled` to `/households/`, writable on create and update, plus read-only `created_at`, `updated_at` and `integration_link_updated_at`.
- 1.18.0 (2026-10-23)
  - Add account details to `/accounts/`: `nickname`, `inception_date`, `close_date`, `relationship_type`, `held_away`, `excluded`, `custodian` (by name), `investment_objective`, `investment_objective_custom`, `exceptions_enabled` and `clients_review_enabled`, writable on create and update.
  - Add read-only `retirement_category` (derived from `type`), `created_at`, `updated_at`, `provider`, `integration_link_updated_at`, `sync_status`, `sync_status_changed`, `next_review_date`, `display_name` and `display_number` to the account object.
  - Creating an account without an `investor` or an `advisor` returns a `400`. A custodian must match its whole name or an alternative name.
- 1.17.0 (2026-10-23)
  - Add the investor suitability profile to `/investors/`: personal details (`date_of_birth`, `marital_status`, `dependants`, `employment_status`, `occupation`, mailing address and countries), investment profile (`investment_objective`, `investment_objective_custom`, `investment_experience`, `investment_experience_level`, `time_horizon`, `time_horizon_bucket`, `liquidity_needs`) and financials (`annual_income`, `annual_expenses`, `special_expenses`, `net_worth`, `liquid_net_worth`, `investable_assets`, `advisory_fee`, `tax_rate`, `tax_bracket`), writable on create and update.
  - Add read-only `created_at`, `updated_at`, `next_review_date`, `integration_link_updated_at` and the `exceptions_enabled`, `clients_review_enabled`, `checkins_enabled` toggles to the investor object.
  - Country codes must be upper-case ISO 3166-1 alpha-2, and the date of birth cannot be in the future. Fields set from the client's paperwork cannot be changed through the API.
  - Prospects: reachable by id, listed with `is_prospect=true`; adding one requires the firm's permission, and turning a prospect into a client excludes its accounts.
- 1.16.0 (2026-10-16)
  - Document the OAuth2 client-credentials grant for server-to-server integrations. These tokens are API-only and cannot start a web session.
  - Add [Single Sign-On](#single-sign-on): SAML service-provider endpoints per org slug, IdP-initiated sign-in, `RelayState` deep-linking and the setup requirements.
- 1.15.1 (2026-10-11)
  - The authorization callback includes the `iss` parameter (RFC 9207).
  - Refresh tokens rotate on every refresh. Reusing a spent refresh token revokes the chain, and a refresh token not used within 30 days of its access token expiring expires.
- 1.15.0 (2026-10-09)
  - Document `matching_model` as the account field that holds the strategy (Model Portfolio id). The field was renamed from `strategy` in the API but the docs kept the old name.
  - `strategy` stays accepted on create and update and is returned alongside `matching_model` as an alias; sending both with different values returns a `400`.
- 1.14.0 (2025-11-06)
  - session token deprecation notice
  - adds OIDC support
  - adds '/o/sso/' for starting a session on stratifi.com
  - adds filtering for provider_name on sources field for household, investor, account and model_portfolio endpoints
- 1.13.0 (2024-07-08)

  - Add `source_id` and `source_provider` filters to `household`, `investor`, `account` and `model_portfolio`.
  - Adds `teams` field to `model_portfolio` and `account`.
